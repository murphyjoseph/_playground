# Domain Profile: Product Comparisons

For "best X for Y" and "A vs B." This domain is saturated with SEO-optimized affiliate content, so the dominant signal is *conflict-of-interest detection*.

## Source tiers (strongest first)

1. **Independent testing with reproducible methodology** — published test setups, raw numbers, disclosed sample provenance
2. **Aggregated user experience** — long-term owner reports, issue trackers, community forums; individually noisy, collectively diagnostic (weight complaints about the same failure mode from independent users heavily)
3. **Vendor documentation and spec sheets** — authoritative for what a product claims to do, never for comparative judgments
4. **Review/listicle sites** — mostly affiliate-driven; usable only after passing the COI screen below

## Conflict-of-interest screen (apply to every review source)

- Affiliate links or "we may earn a commission" disclosures → the ranking incentive is conversion, not accuracy. Not disqualifying alone, but demands corroboration.
- Did they actually test the product? Look for original photos, measured numbers, and failure observations. Spec-sheet rewrites with stock images are not reviews.
- "Best of" lists where every item links to the same retailer, or where the top pick changes with commission rates, are ads.
- Vendor-sponsored comparisons and "independent" benchmarks commissioned by one competitor: treat as vendor content.

## Benchmark rules

- Prefer benchmarks with published, reproducible methodology; discount any benchmark you couldn't in principle rerun.
- Check whether the benchmark's conditions match the user's use case — winning an unrepresentative benchmark is a marketing artifact.
- Cross-check vendor performance claims against at least one independent measurement before repeating them.

## Output posture for this domain

Separate three things explicitly in the answer: what independent testing shows, what users report over time, and what the vendor claims. When the honest answer is "no independent testing exists," say that rather than laundering vendor claims through neutral phrasing. Recommendations should state the use-case assumptions they depend on — "best" is always conditional.
